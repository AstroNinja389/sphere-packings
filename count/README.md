# Short-pair counts in dimensions 11 and 12

The dimension-11 certificate uses a theorem about ten short pairs. The dimension-12 certificate uses a theorem about eleven. Each proof combines the bound for the case where the count threshold is met with the bound for its complement. The premise files identify the geometric lemmas and finite tables. The repository includes the table programs and audit records. Some original tables are external.

A SHARPER LEVEL LIMIT FOR THE CELL SCHEME: (SMALL3)                                               v1, 2026-11-18
=====================================================================================================================
Status: elementary; one author (Claude), one session; NOT reviewed at the time of writing. It replaces the number
SMALLB of the lemma-table programs (the level below which cells with sum t_i <= 2 are no longer excluded) by a smaller
one. Nothing else in the programs changes (generator make_s3_variants_v1.py).

SETTING (that of the scheme).  N >= 4 coordinates. Q' = I + diag(delta) + E on R^N, delta_a in [0, 1/8],
sum_a delta_a <= D0, E symmetric with zero diagonal, |E_ab| <= (delta_a + delta_b)/2.  D_N := the vectors of Z^N with even
coordinate sum. For q in R^N: t_a := distance of q_a to Z (in [0, 1/2]), Y := sum_a t_a, m := max_a t_a,
N(q) := min of Q' over q + D_N.

LEMMA (SMALL3).  If Y <= 2, then
      N(q) <= S3(D0) := 1 + max{ D0, 3/8, phi(m*) },
      phi(m) := (3 - 2m) (1/8 + (D0 - 1/4) m),   m* := (3 (D0 - 1/4) - 1/4) / (4 (D0 - 1/4)),
where phi(m*) is included only if D0 > 1/4 and 0 < m* < 1/2.
Values: S3(1/4) = 11/8 = 1.375;  S3(3/8) = 89/64 = 1.390625 (m* = 1/4);  S3(1/2) = 3/2.
(The old numbers: (SMALL') 1 + max(1, (1 - 2/N)(3 - 4/N)) D0, e.g. 1.78 for N = 10 and 1.809 for N = 11 at D0 = 3/8.)

PROOF.
(X)  For every real vector w:  Q'(w) <= |w|^2 + |w|_1 sum_a delta_a |w_a|.
     [Q'(w) = sum_a (1 + delta_a) w_a^2 + sum_{a != b} E_ab w_a w_b <= |w|^2 + sum_a delta_a w_a^2
      + sum_{a != b} ((delta_a + delta_b)/2) |w_a| |w_b|, and the last sum is sum_a delta_a |w_a| (|w|_1 - |w_a|).]
Let w0 be the vector congruent to q modulo Z^N with |w0_a| = t_a for all a. The class q + D_N either contains w0
("even class") or contains w0 - s e_i for every coordinate i and both signs s ("odd class": the integer shift between q and
w0 has odd coordinate sum, and adding +-e_i makes it even).
Even class.  |w0|^2 = sum t_a^2 <= m Y, |w0|_1 = Y, sum_a delta_a t_a <= D0 m.  By (X):
      N(q) <= m Y + Y D0 m = m Y (1 + D0) <= 1 + D0            (Y <= 2, m <= 1/2).
Odd class.  Take i with t_i = m and the sign s for which the i-th entry of w := w0 - s e_i has absolute value 1 - m.
The other entries have absolute value t_a <= m and sum Y - m, so
      |w|^2 <= m (Y - m) + (1 - m)^2 = 1 - m (2 - Y) <= 1,          |w|_1 = Y + 1 - 2m <= 3 - 2m,
      sum_a delta_a |w_a| <= delta_i (1 - m) + (D0 - delta_i) m = D0 m + delta_i (1 - 2m) <= D0 m + (1 - 2m)/8
(delta_i <= 1/8 and 1 - 2m >= 0). By (X):
      N(q) <= 1 + (3 - 2m) (D0 m + (1 - 2m)/8) = 1 + phi(m),       0 <= m <= 1/2.
phi is the quadratic 3/8 + (3c - 1/4) m - 2c m^2 with c := D0 - 1/4; phi(0) = 3/8, phi(1/2) = 2 (1/8 + c/2) = D0.
If c <= 0, phi is convex (or linear), so its maximum on [0, 1/2] is at an end point. If c > 0, phi is concave with vertex
m* = (3c - 1/4)/(4c); its maximum on [0, 1/2] is phi(m*) if 0 < m* < 1/2 and otherwise at an end point.
In all cases N(q) <= 1 + max{D0, 3/8, phi(m*) [if c > 0 and 0 < m* < 1/2]}, and the even class gives 1 + D0.          QED

USE.  A cell of the scheme with sum t_i <= 2 (for q) or sum t'_i <= 2 (for 2q; t' the distances of 2q to Z, and N(2q) is
the same function evaluated at 2q) contains no point with N >= 2 - level as soon as 2 - level > S3(D0). The programs
exclude these cells under the condition 2 - level > SMALLB; with SMALLB := min(old number, S3(D0)) the condition is weaker
and the exclusion remains valid. At D0 = 3/8 levels up to 0.609 are allowed (before: 0.22 for N = 10, 0.19 for N = 11).

REMARK.  The proof uses delta_a <= 1/8 for the flipped coordinate only. The earlier (SMALL'') of
../two-pairs-fewer-20261118/make_frame_u2h_v1.py (1 + (3 - 4/N)^2/8) is weaker and is not needed.

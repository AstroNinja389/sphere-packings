1. STATEMENT
THEOREM N15.  Let L be a fifteen-dimensional lattice of minimum squared length 1, and let x_1, ..., x_15 in L lie in
one class modulo 2L, with x_i != +-x_j for i != j and |x_i|^2 <= 9/4 for all i. (The class is then not the zero
class: a non-zero vector of 2L has squared length >= 4, and x_i != +-x_j excludes two zero vectors.) If
      sum_i max(|x_i|^2, 2) <= 30 + 3/4,
then  density(L) <= density(Lambda15) = 8 sqrt(2) pi^7 / 15!! = 0.0168575706567...
COROLLARY (the form used by the linear programme).  If density(L) > density(Lambda15), then for any fifteen distinct
pairs of one class modulo 2L, each of squared length <= 9/4:
      (i)   sum_i max(|x_i|^2, 2) > 123/4,
      (ii)  sum_i |x_i|^2 > 30 + 39/56.
In bins: a class has at most one pair below 2 (for two pairs of one class |x_i|^2 + |x_j|^2 >= 4). Let u_s be the upper
end of the bin of that pair, if there is one, and Sigma the sum of the upper bin ends of the other pairs. Then
      Sigma + min(2, u_s + 3/56) > 123/4        (without a pair below 2: Sigma > 123/4),
from (i) and (ii), because 123/4 - (30 + 39/56) = 3/56.

2. PROOF
Reduction (as in section 2 of ../n16-fifteen-frame-assembled-20261117/FRAME-THEOREM-D104_175-v1.txt, with fifteen
dimensions instead of sixteen). Put d_i = |x_i|^2 - 2. For i != j the vectors x_i +- x_j are non-zero elements of 2L,
so d_i + d_j >= 0 and |x_i . x_j| <= (d_i + d_j)/2; at most one d_i is negative. Lambda := sqrt 2 L has minimum 2,
f_i := x_i/sqrt 2, and Gamma := {sum c_i f_i : c in D15} is contained in Lambda. In the coordinates of the f_i the norm is
      Q = diag(1 + delta_i) + E,  delta_i = d_i/2 <= 1/8,  delta_i + delta_j >= 0,  |E_ij| <= (delta_i + delta_j)/2,
and the hypothesis reads  sum_i max(delta_i, 0) <= 3/8.  In particular Delta := sum delta_i <= 3/8.
 (D) det Q >= 1.   DETERMINANT-LEMMA-v1.txt, Lemma D (a) if all delta_i >= 0, (b) if one is negative; both need
     Delta <= 3/8. Hence the f_i are independent, Gamma has rank 15 and covolume 2 sqrt(det Q) (D15 has covolume 2),
     and Gamma has finite index j in Lambda:   covol(Lambda) = 2 sqrt(det Q) / j.
 (G) j <= 16.   G := Lambda/Gamma is a finite subgroup of R^15/D15 (frame coordinates) all of whose non-zero classes
     consist of non-zero vectors of Lambda, hence are valid (N_Q >= 2). GLUE-INDEX-REDUCTION-v2.txt, Proposition G (b):
     j (z + 1) <= 16, given Lemma DV(Delta0) for a Delta0 with sum_i max(delta_i, 0) <= Delta0. (The proposition
     states the frame case as (14/13) Delta <= Delta0; its proof, Step 1, uses only sum max(delta_i, 0) <= Delta0.
     Here Delta <= 3/8 gives (14/13) Delta <= 21/52, so at Delta0 = 21/52 the proposition applies as literally stated.)
     Lemma DV(21/52): ../n16-fifteen-frame-item4-20261116/DV-21_52-FULL-RANGE-RESULT-v1.txt; 3/8 <= 21/52.
 So covol(Lambda) >= 2/16 = 1/8, covol(L) = 2^(-15/2) covol(Lambda) >= 2^(-21/2), and
      density(L) = V_15 2^(-15) / covol(L) <= V_15 2^(-9/2) = V_15/(16 sqrt 2) = density(Lambda15),
 V_15 = pi^(15/2)/Gamma(17/2) the volume of the unit ball; the last number is 8 sqrt(2) pi^7/15!!.              QED
Corollary: (i) is the contrapositive. (ii): if sum |x_i|^2 <= 30 + 39/56 =: 30 + D and d_1 = -2 nu < 0, then every
other d_j >= 2 nu, D >= 26 nu, and sum max(|x_i|^2, 2) <= 30 + D + 2 nu <= 30 + (14/13) D = 30 + 3/4, against (i);
without a negative d_i the sum is 30 + D < 30 + 3/4.

3. REMARKS
 - Sharpness of the conclusion: Lambda15 is the lattice generated by D15 and c/2, c in the simplex code [15,4,8]
   (index 16, covolume 1/8 at minimum 2), so it contains an exact fifteen-frame and equality holds for it. Only the
   number 8 sqrt(2) pi^7/15!! is used in the proof. (The reviewer checked for this lattice: minimum 2, covolume 1/8,
   420 + 15*128 = 2340 minimal vectors, the kissing number of Lambda15.)
 - Neither item (iv) of the fifteen-frame theorem nor the covering certificate (Theorem P) is used: those bound the
   height of a sixteenth direction, and here there is none.
 - Smaller range without the newest lemma: with Lemma DV(8/25) (GLUE-INDEX-REDUCTION-v2-ADDENDUM-D8_25-v1.txt) in place
   of DV(21/52) the same proof gives the statement with 30 + 16/25 instead of 30 + 3/4 (and 30 + 104/175, 8/175 in
   place of 30 + 39/56, 3/56).
 - The range 3/8 is where Lemma D is proved; Proposition G would allow 21/52.

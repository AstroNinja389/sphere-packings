2. CELL FORMS OF THE OLDER BOUNDS
Rule for (B0e), (B0o), (B3), (B2), (AM): in the class form an aggregate Y enters the coefficient of each coordinate;
it is replaced by the upper end y of its cell where it multiplies a non-negative quantity, and 1/Y by the reciprocal
of the lower end. Since delta_i >= 0 and the multiplied quantities (u_i, t_i, t_i(1 - 2 t_i)) are >= 0, the cell form
dominates the class form coordinate by coordinate.
(L1), distinguished coordinate k (the one member of H_j), class form (GLUE-INDEX-REDUCTION-v2.txt, section 4):
   N_Q <= (1+delta_k)(1/4 + e_k^2) + sum_{i != k} (1+delta_i)(t_i^2 + t_i(1-2t_i)/(2Y'))
          + (1 - 1/Y') sum_{i != k} delta_i t_i (Y' - t_i) + (delta_k Y' + Z')(e_k + (1/2 + e_k)/(2Y')),
   Y' = sum_{i != k} t_i = Y_j - e_k,  Z' = sum_{i != k} delta_i t_i,  valid for Y' >= 1.
 Cell quantities: y := y_{c_j} (upper end of the cell of Y_j), ylo := y_{c_j - 1} - (1/2 - tau_j), eb := 1/2 - tau_j.
 On the cell: Y' <= Y_j <= y;  Y' = Y_j - e_k > y_{c_j - 1} - eb = ylo (because e_k <= eb, k being in H_j);  e_k <= eb.
 The bound is used only if ylo >= 1 (the programs: only if the rounded-down ylo is > 1), which gives Y' >= 1.
 Cell form, per coordinate (f0 + delta f1):
   member (i = k):   f0 = 1/4 + e^2,                      f1 = f0 + e y + (1/2 + e)/2;
   other  (i != k):  f0 = t^2 + t(1 - 2t)/(2 ylo),        f1 = f0 + t(y - 1) - (1 - 1/ylo) t^2 + t (eb + (1/2 + eb)/(2 ylo)).
 Domination, term by term:
   member:  the class coefficient of delta_k is (1/4 + e_k^2) + Y'(e_k + (1/2 + e_k)/(2Y')) = f0 + e_k Y' + (1/2 + e_k)/2
            <= f0 + e_k y + (1/2 + e_k)/2, by Y' <= y;
   other, constant part:  t(1 - 2t)/(2Y') <= t(1 - 2t)/(2 ylo), by Y' >= ylo and 1 - 2t >= 0;
   other, delta part:  (1 - 1/Y') t (Y' - t) = t(Y' - 1) - (1 - 1/Y') t^2 <= t(y - 1) - (1 - 1/ylo) t^2
            (Y' <= y; and 1/Y' <= 1/ylo makes the subtracted term at least (1 - 1/ylo) t^2);
            t (e_k + (1/2 + e_k)/(2Y')) <= t (eb + (1/2 + eb)/(2 ylo)), by e_k <= eb and Y' >= ylo.
 All replaced factors multiply delta_i >= 0 or are constants, so the sum over coordinates of the cell form is >= the
 class form >= N_Q. (Numerical confirmation by reviewer 3: 3,325 cell instances, least (cell - class) 1.4e-3.)

3. BOUNDARY CONVENTIONS
 1. A pair (Q, g) is assigned to cells by the half-open intervals of section 1, so it lies in exactly one cell
    (and, after subdivision, in exactly one piece).
 2. A certificate uses the closed constraints Y_j <= y_{c_j} and (only if c_j >= 2) Y_j >= y_{c_j - 1}; these are weaker
    than membership, hence valid on the cell.
 3. "Empty" rows (k_j = 0 forces Y_j = Y_0 while the intervals of Y_j and Y_0 are disjoint as half-open sets) and the
    rule that skips impossible pieces in a subdivision (upper end of the interval of Y_j at most the lower end of
    that of Y_{j+1}) rely on the half-open assignment and on Y_j >= Y_{j+1}.
 4. Y_j = 0 is not in (0, 2]; for c_j = 1 no lower constraint is imposed, so the certified set is [0, 2].
 5. A coordinate with t = tau_j: the box of s below a threshold is evaluated with both memberships. A coordinate with
    t = 1/2 or t' = 1/2 (the parity of the class then depends on the representative): both parities are separate
    cases, and every constraint holds for the representative chosen.
 6. No relation between the parity of 2g and g is assumed: all nine 2g-cases are run for all forty g-cases.
 Y_0 >= Y_1 >= Y_2 >= Y_3 holds because t >= e on members of H_j (tau_j > 1/4).

4. NOTATION IN (B3)
In GLUE-INDEX-REDUCTION-v2.txt, section 4, the formula  N_Q <= sum_i [u_i^2 + 1_H(i)(1+delta_i)/4] + Z_H Y_H  is to be
read with  Y_H = sum over ALL fifteen coordinates of u_i  and  Z_H = sum over ALL fifteen of delta_i u_i  (u = e on H,
t off H). Read as sums over H only, the formula is false (reviewer 3: below the exact minimum in 32 of 128 trials).
The programs use the correct reading.

5. WHERE TEXT AND PROGRAMS DIFFER (none affects validity)
 - GLUE 7.1 gives the constant in the rule for H' as "the float nearest 0.14"; the programs use Delta0/2 (0.2019 at
   21/52). (B3) holds for any set of at least three coordinates, so the constant does not matter.
 - DV-21_52-FULL-RANGE-RESULT-v1.txt cites (SMALL) for the excluded cells; the programs assert (SMALL'). Both hold.
 - The texts say "Dlo >= 1", "D'lo >= 1/2", "ylo >= 1"; the programs use a bound only for strict inequality.
 - GLUE 7.1 lists B0/B3/B2/L1 and the 2g bound only; (F), (G), (M) were added on 16 November (section 1 above).
 - "at most 4 halvings" in the result file: 4 is the cap of the first program, the deepest piece has depth 3.
 - "No negative multiplier" in the result file means none on an inequality; multipliers of count equalities may be
   negative (and are, in 100,679 stored entries).
 - Stale status lines: the header and section 8 of GLUE-INDEX-REDUCTION-v2.txt still say DV(21/52) is not proved, and
   the result file says a written proof of (F), (G), (M) is owed; both were superseded on 17 November.
 - recheck_dv_v2.py, cells mode: the covering is checked from the stored field `cell` and filed under the stored
   index `ci` without asserting that they agree (reviewer 4 checked all 608 files: they agree). The re-check output
   does not record the part index or the table scheme (the queue logs do).

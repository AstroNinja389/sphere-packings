0. SETTING
Q = diag(1 + delta_i) + E on R^15, |E_ij| <= cap_ij = (delta_i + delta_j)/2, delta_i <= 1/8.
 Frame case: delta_i + delta_j >= 0, sum delta_i = Delta <= 3/8 (trace excess D = 2 Delta <= 3/4); at most one
 delta_i is negative.   Non-negative case: all delta_i >= 0, sum delta_i <= Delta0.
For q in R^15:  N_Q(q) := min { Q(v) : v in q + D15 },   psi(q) := sum_i cos(2 pi q_i)   (psi is Z^15-periodic).
A class q + D15 is VALID (for Q) if N_Q(q) >= 2.
The section M = Lambda n V of a lattice Lambda of minimum 2 containing the frame lattice D15 (in the coordinates of
the frame) gives a finite subgroup G = M/D15 of R^15/D15 all of whose non-zero classes are valid; j = |G|;
z = number of coordinates i with g_i in Z for every g in G.

1. STATEMENTS
LEMMA DV(Delta0) (two-class lemma).  Let all delta_i be in [0, 1/8], sum delta_i <= Delta0. If g and 2g are both
valid for Q, then psi(g) < -1.
   Status: DV(7/25) checked by computer (section 7). DV(21/52) NOT PROVED.
   (Exact case Q = I: psi(g) <= about -5, by section 9 of EXACT-FRAME-THEOREM-v1.txt. Probe, section 5: the largest
   value found at Delta0 = 21/52 is -3.23 for classes of even parity and -3.35 for odd parity.)

PROPOSITION G (proved, given Lemma DV(Delta0)).  Let Q be in the frame case with (14/13) Delta <= Delta0, or with all
delta_i >= 0 and Delta <= Delta0. For every G as above:
   (a) every element of order 2 is c/2 modulo Z^15 with c a 0/1 word of even weight >= 8
       [no use of Lemma DV; holds in the whole frame case Delta <= 3/8];
   (b) j (z + 1) <= 16;
   (c) if j = 16, then G is the simplex-code group: every non-zero class is c/2 with c of weight 8, and the fifteen
       coordinate columns are the distinct non-zero functionals. That is Assumption A1.
 With Delta0 = 21/52 this is the whole frame case. With Delta0 = 7/25 it is: Delta <= 0.26 (D <= 0.52) in the frame
 case, Delta <= 0.28 (D <= 0.56) when all delta_i >= 0.

2. PROOF OF PROPOSITION G
Step 1 (one negative entry). If delta_1 = -nu < 0, then delta_j >= nu for j >= 2, so Delta >= 13 nu.
Q' := Q + nu e_1 e_1^t has delta'_1 = 0, the same E, |E_1j| <= (delta_j - nu)/2 <= (delta'_1 + delta'_j)/2, and
sum delta' = Delta + nu <= (14/13) Delta <= Delta0 (for Delta <= 3/8: <= 21/52). Q' >= Q, so N_Q' >= N_Q: every
class valid for Q is valid for Q'. So it is enough to treat all delta_i >= 0, sum delta_i <= Delta0 <= 21/52.
Step 2 (order 2).  2g in D15 means g in (1/2) Z^15 with sum 2 g_i even. If g is integral it is an odd vector, and
Q(e_i) = 1 + delta_i < 2: not valid. Otherwise g = c/2 mod Z^15, c a non-zero 0/1 word, and the parity condition
makes its weight w even. The vectors of the class with all entries in {0, +-1/2} are the sign patterns on the
support of c with a fixed parity of the number of minus signs. For w >= 4 their average has E s_i s_j = 0 (i != j),
so the shortest has Q-norm <= w/4 + delta(supp c)/4 <= (w + 21/52)/4, which is < 2 for w <= 6; for w = 2 any of them
has Q-norm <= (2 + delta_a + delta_b)/4 + cap_ab/2 < 1. Hence w >= 8, and psi(g) = 15 - 2w <= -1.
Step 3 (other elements).  If 2g != 0 in G, both g and 2g are non-zero classes of G, hence valid; Lemma DV gives
psi(g) < -1.
Step 4 (group identity).  For i not in the set of uncovered coordinates, g -> exp(2 pi i g_i) is a non-trivial
character of G, so sum_{g in G} psi(g) = j z. With psi(0) = 15 and psi(g) <= -1 for g != 0:
      j z <= 15 - (j - 1),   i.e.   j (z + 1) <= 16.
Step 5 (j = 16).  Then z = 0 and every non-zero g has psi(g) = -1 exactly. By Step 3 (strict inequality) no element
has 2g != 0, so G is elementary abelian of order 16, a binary linear code of length 15 with all non-zero weights
even, >= 8, and 15 - 2w = -1: all weights are 8. The counting argument of section 1 of SIMPLEX-SECTION-THEOREM-v1.txt
(sum of weights = 120 = 8 * number of non-zero columns; sum of squared weights forces distinct columns) gives the
simplex code.                                                                                                   QED

3. WHAT THE COVERING THEOREM REALLY USES (remark; proved)
The selection step of ROBUST-COVERING-LEMMA-v1.txt / PARITY-CERTIFICATE-v1.txt uses A1 only through
      sum_{m in G} c_i(y+m) = 0,   sum_{m in G} c_i c_j (y+m) = 0,   sum_{m in G} S_i S_j (y+m) = 0   (i != j, all y),
c = cos 2 pi q, S = sin 2 pi q. Since c_i c_j and S_i S_j are (cos(q_i - q_j) +- cos(q_i + q_j))/2, these hold exactly
when, for all i != j, the characters chi_i, chi_i chi_j and chi_i chi_j^{-1} of G are non-trivial (chi_i(g) =
exp(2 pi i g_i)). Call such a G of STRENGTH TWO. Theorem P is a statement about a single class, so:
   for every section whose glue group has strength two, every y has Q-distance^2 < 1.81786 from M (non-negative
   delta, sum <= 3/8; 1.837 in the one-negative case as in section 8 of the parity file; status of Theorem P as
   stated in those files).
With j <= 16 (Proposition G) and det Q >= 1 this excludes a contender for EVERY strength-two section, not only the
simplex one, because the height threshold (j/16)^2 * 0.18214/det Q only decreases with j.
So, wherever Lemma DV is available, open item (iv) shrinks to the sections that are NOT of strength two: some
coordinate uncovered (z >= 1), or two coordinates i != j with g_i = +-g_j for all g in G ("repeated columns").

4. UPPER BOUNDS FOR N_Q (all proved; these are the tools for Lemma DV)
Non-negative case. Write q = n + r, n integral, |r_i| <= 1/2, t_i = |r_i|, e_i = 1/2 - t_i, p = sum n_i mod 2 (the
parity of the class). After changing signs of coordinates (E_ij -> E'_ij = E_ij sgn r_i sgn r_j, same caps) the
vectors of the class with at most one flip per coordinate are z = (t_i - f_i), f in {0,1}^15, sum f_i = p mod 2, and
      Q(z) = sum (1+delta_i) z_i^2 + sum_{i != j} E'_ij z_i z_j.
For any probability measure on admissible f:   N_Q(q) <= sum (1+delta_i) E z_i^2 + sum_{i != j} cap_ij |E z_i z_j|.
If E z_i z_j = mu_i mu_j for i != j (means mu), then with u_i = |mu_i|, Y = sum u_i, Z = sum delta_i u_i:
      sum_{i != j} cap_ij u_i u_j = sum_i delta_i u_i (Y - u_i) = Z Y - sum delta_i u_i^2.
(B3) H a set of at least three coordinates, f uniform on the patterns on H with the right parity, f = 0 off H.
     The f_i (i in H) are uniform and pairwise independent; mean -e_i, second moment 1/4 + e_i^2 on H. Hence
        N_Q <= sum_i [ u_i^2 + 1_H(i)(1+delta_i)/4 ] + Z_H Y_H,     u = e on H, t off H.            (parity free)
(B2) H = {a, b}: the two patterns of the right parity, each with probability 1/2. Marginals as before,
     E z_a z_b = e_a e_b +- 1/4.  N_Q <= (B3 formula) + cap_ab/2 = (B3 formula) + (delta_a + delta_b)/4.
(B1) H = {k}: the sign of coordinate k is forced; |z_k| <= 1/2 + e_k.  N_Q <= sum u'^2 + (sum delta u')(sum u'),
     u'_k = 1/2 + e_k, u' = t elsewhere.
(B0e) p even, nearest vector:  N_Q <= sum t_i^2 + (sum delta_i t_i)(sum t_j).
(B0o) p odd, Y = sum t_i >= 2: flip exactly one coordinate, coordinate i with probability t_i/Y. Then
     E z_i^2 = t_i^2 + t_i(1-2t_i)/Y, E z_i z_j = t_i t_j (1 - 2/Y), and
        N_Q <= sum_i [ t_i^2 + delta_i t_i (Y - 2 + 2 t_i/Y) + (1+delta_i) t_i (1 - 2 t_i)/Y ].
(L1) one distinguished coordinate k, Y' = sum_{j != k} t_j >= 1, Z' = sum_{j != k} delta_j t_j: with probability 1/2
     flip k, together with (p even) or instead of (p odd) one other coordinate J, P(J = j) = t_j/Y'. Then
        N_Q <= (1+delta_k)(1/4 + e_k^2) + sum_{j != k} (1+delta_j)(t_j^2 + t_j(1-2t_j)/(2Y'))
               + (1 - 1/Y') sum_{j != k} delta_j t_j (Y' - t_j) + (delta_k Y' + Z')(e_k + (1/2 + e_k)/(2Y')).
(AM) for (B3): sum_{i != j} cap_ij u_i u_j <= sum_i A_i u_i^2, A_i = sum_{j != i} cap_ij = (13 delta_i + Delta)/2,
     which needs no aggregate quantity: N_Q <= sum_{off H} w_i t_i^2 + sum_{H} ((1+delta_i)/4 + w_i e_i^2),
     w_i = 1 + delta_i + A_i.
(SMALL) if sum t_i <= 2 then N_Q < 2.  [With m = max t_i and one flip at the largest coordinate if needed:
     Q <= m Y + 1 - 2m + (Y + 1 - 2m)^2/8, increasing in Y; for m >= 2/15 at Y = 2 it is 1 + (3-2m)^2/8 <=
     1 + 1681/1800 < 2; for m < 2/15 at Y = 15 m it is convex in m with values 9/8 and < 1.94 at the ends.]
Floating-point sanity test (proves nothing): test_glue_bounds_v2.py, 200 random classes, random and adversarial E,
exact minimum over all 2^14 lifts: 8,200 comparisons, no bound below the exact value (log test-glue-bounds-v2-seed7.log).
Tightness: eval_bounds_on_probe_v1.py - at the eleven feasible end points of the even-parity probe the least value
of (B0e)/(B3) over all H is 2.0000-2.0101 for g (attained by H = empty) and 2.16-2.45 for 2g.

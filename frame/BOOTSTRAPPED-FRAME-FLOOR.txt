1. THEOREM B
Let n >= 9, d_n := V_n 2^(-n/2-1) (the density of D_n), B an upper bound for the density of lattices in dimension n,
J >= 1 an integer with (J+1) d_n > B, D0 a range at which the determinant lemma holds in dimension n, and S0 a number with
        0 < S0 <= 2 D0     and     S0 < 4 ln((J+1) d_n / B).                                                   (*)
Then a lattice L of dimension n and minimum 1 with density(L) > J d_n has no n distinct pairs of one class modulo 2L,
each of squared length < 9/4, with sum max(|x|^2, 2) <= 2n + S0.
Proof (written out with the numbers of each instance in the premise files BOOT-PREMISE-n<n>-r<k>.txt). Suppose such
pairs x_i exist. (1) d_i := |x_i|^2 - 2; x_i +- x_j are non-zero elements of 2L, so d_i + d_j >= 0 and
|x_i . x_j| <= (d_i + d_j)/2; with Lambda := sqrt 2 L and f_i := x_i/sqrt 2 the lattice Gamma := {sum c_i f_i : c in D_n}
lies in Lambda, and the Gram matrix Q of the f_i has diagonal 1 + delta_i, delta_i = d_i/2 <= 1/8, off-diagonal entries
bounded by (delta_i + delta_j)/2, and sum max(delta_i, 0) <= S0/2 <= D0. (2) det Q >= 1 (determinant lemma), so Gamma
has rank n and covolume 2 sqrt(det Q), j := [Lambda : Gamma] is a positive integer, and
density(L) = j d_n/sqrt(det Q). (3) density(L) > J d_n and det Q >= 1 give j > J, so j >= J + 1. (4) density(L) <= B gives
sqrt(det Q) >= (J+1) d_n/B. (5) Hadamard: det Q <= prod (1 + delta_i) <= exp(sum delta_i) <= exp(S0/2). (6) So
S0 >= 4 ln((J+1) d_n/B), against (*).                                                                         QED
The whole content: THE INDEX IS AN INTEGER. Step (3) needs det Q >= 1; in dimension 2, where the lemma is not claimed,
the conclusion is false (referee's example).

2. USE AND ITERATION
The frame case of the auditor (index_cap = J, S0, T = 9/4) gives an audited density B' for lattices denser than J d_n;
the final bound is max(B', J d_n). If J d_n <= B' < B the theorem applies again with B' in place of B.
Induction (U_k := "every lattice of the dimension has density <= B_k"; P_k := the statement of premise file k):
U_(k-1) and the determinant lemma imply P_k (it uses B_(k-1), never B_k); P_k and the audit of round k imply U_k.
So U_0 => P_1 => U_1 => P_2 => ... , strictly forward. The proof of the last bound uses U_0, the determinant lemma,
and the verified class budget in each round. Every premise file and audit in the chain is part of the proof.
J must be at most floor(B/d_n), and J d_n has to end below the bound.

4. THE SHARPENING: THEOREM B2 (odd-order exclusion)
The index j is the order of the group G = Lambda/Gamma inside R^n/D_n, all of whose non-zero classes have norm >= 2.
Lemma O(n, D, p) of ODD-ORDER-EXCLUSION-v1.txt: for the checked triples (n, D, p), p an odd prime, G has no element of
order p (the multiples of such an element cannot all have norm >= 2: a finite computation over residue patterns, with
the elementary bound Q'(w) <= |w|^2 + |w|_1 sum delta_a |w_a|, and for p = 3 an average over the flipped coordinate).
By Cauchy's theorem j is then not divisible by p.
THEOREM B2.  n, B, d_n, D0 as in Theorem B, S0 <= 2 D0, J >= 1, JTOP := the largest integer below (B/d_n) exp(S0/4).
If every integer j with J < j <= JTOP is divisible by an odd prime p for which Lemma O(n, D0, p) holds, then a lattice of
dimension n and minimum 1 with density > J d_n has no n distinct pairs of one class modulo 2L, each of squared length
< 9/4, with sum max(|x|^2, 2) <= 2n + S0.
Proof (premise files BOOT2-PREMISE-n<n>-r<k>.txt): as Theorem B up to j > J; Hadamard and density <= B give
j <= (B/d_n) exp(S0/4), so J < j <= JTOP; such a j has a forbidden prime factor.                              QED

The sweep report DIMENSION-10-REPORT-v1.json mentions a "prior stronger bound pi^5/(120 * 2^(35/8)) < 0.122903". That
number is Mordell's inequality applied to gamma_9 = 2, the conjectured value, not a proved bound. I know of no proved
bound for lattices in dimension 10 below 0.129; to be checked by the owner before the dimension-10 value is used.

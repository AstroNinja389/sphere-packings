# Frame certificates

These earlier proofs combine a Fourier certificate with estimates for a lattice containing many short pairs in one parity class. Each dimension's premise file gives the determinant, index or glue lemma used in the estimate. The replay checks the finite class budgets. The review and availability of the geometric inputs are recorded separately. [Inputs and review history](../EARLIER-CERTIFICATES.md)

For example, the dimension-13 frame proof gave **0.047947694667495** using the determinant and odd-order glue lemmas. The current **0.042023513562578** follows from Mordell's inequality and the published rank-12 theorem. [Current bounds and proofs](../sections/README.md)

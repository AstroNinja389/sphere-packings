# Joint-cut certificates

These certificates use simultaneous constraints on several short vectors. Each dimension has its own inputs. For example, the dimension-13 calculation gives **0.0486832075907** for all lattices in that dimension. The dimension-11 and dimension-12 short-pair theorems are documented in the separate count folder. [Earlier results and proof inputs](../EARLIER-CERTIFICATES.md) · [Current bounds](../README.md)
